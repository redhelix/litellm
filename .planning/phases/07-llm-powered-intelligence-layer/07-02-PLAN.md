<sql_queries>
-- 24h aggregates per model
SELECT model,
       COUNT(*) as request_count,
       AVG(ttft_ms) as avg_ttft_ms,
       quantile_cont(ttft_ms, 0.95) as p95_ttft_ms,
       AVG(total_latency_ms) as avg_latency_ms,
       AVG(context_utilization) as avg_ctx_util,
       SUM(CASE WHEN status='failed' THEN 1 ELSE 0 END) * 1.0 / COUNT(*) as error_rate,
       SUM(CASE WHEN tool_call_status='repaired' THEN 1 ELSE 0 END) as tool_repairs
FROM requests
WHERE startTime > NOW() - INTERVAL 24 HOUR
GROUP BY model
ORDER BY request_count DESC;

-- recent error clusters
SELECT model, error_message, COUNT(*) as occurrences
FROM requests
WHERE startTime > NOW() - INTERVAL 6 HOUR
  AND status='failed' AND error_message IS NOT NULL
GROUP BY model, error_message
ORDER BY occurrences DESC LIMIT 10;

-- 7d trend
SELECT DATE_TRUNC('day', startTime) as day, model, AVG(total_latency_ms) as avg_latency_ms
FROM requests
WHERE startTime > NOW() - INTERVAL 7 DAY
GROUP BY day, model
ORDER BY day DESC, model;
</sql_queries>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar → litellm-proxy | Internal Docker network (litellm-internal); Bearer auth via LITELLM_BENCH_KEY |
| sidecar → huggingface.co | Public internet egress; unauthenticated read-only |
| browser → /api/intelligence/query | Cross-origin POST from dashboard; CORS-restricted to http://docker-001:4002 |
| LLM response → DuckDB | Untrusted LLM-generated text persisted as TEXT (anomalies/recommendations as JSON strings) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | I (Info Disclosure) | LITELLM_BENCH_KEY in Bearer header | mitigate | Read from env only; never log; reuse existing key (no new secret added). main.py line 34 assertion still blocks LITELLM_MASTER_KEY leak |
| T-07-06 | T (Tampering) | LLM-returned JSON for anomalies/recommendations | mitigate | json.loads inside try/except; fallback to []; never eval(); store raw string in DuckDB TEXT column (no SQL injection vector — parameterized) |
| T-07-07 | D (DoS) | POST /intelligence/query unbounded question | mitigate | Pydantic max_length=1000 on question; LLM timeout=120s prevents hang; CORS limited to dashboard origin |
| T-07-08 | D (DoS) | HF Hub rate limit (anonymous ~100/h) | accept | Job runs once per 12h with max_instances=1; well under limit; on rate-limit error returns cached results without crashing |
| T-07-09 | I (Info Disclosure) | metrics context sent to local LLM | accept | LLM is local (litellm-proxy on internal network); per CONTEXT constraint "Local-only — no external data egress beyond LiteLLM proxy calls" |
| T-07-10 | E (Elevation) | answer_question raw question concatenated into prompt | mitigate | Question wrapped in user role only; system prompt instructs analyst persona; no tool calling exposed; 1000-char cap limits prompt-injection payload size |
</threat_model>
