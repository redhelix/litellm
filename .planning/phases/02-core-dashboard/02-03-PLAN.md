<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| /api/nodes response → DOM | deployment_state and model strings rendered in badges/headings (React-escaped) |
| /api/models response → DOM | model alias used as react key and rendered as heading; no HTML interpolation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Tampering / XSS | model alias / deployment_state strings rendered in DOM | mitigate | JSX interpolation only. No `dangerouslySetInnerHTML`. Tooltip content built from typed primitives, not raw response strings. |
| T-02-11 | Information Disclosure | Tooltip could expose unintended fields | mitigate | Tooltip content is hand-picked per UI-SPEC (value + unit). Do not stringify raw API row into tooltip. |
| T-02-12 | Repudiation | Status derivation hides underlying deployment_state numeric | accept | Tooltip on status badge includes raw deployment_state and last_scrape ISO for operator debugging (UI-SPEC hover contract). |
| T-02-13 | DoS | Rendering 5+ nodes × 7+ models each tick | accept | N is tiny (~12 rows + 7 cards); React 19 + stable keys. No virtualisation needed. |
</threat_model>
