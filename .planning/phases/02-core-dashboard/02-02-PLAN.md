<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser JS → sidecar /api/* | Cross-origin fetch gated by CORS (established in Plan 01) |
| user DOM → rendered model names/deployment data | API response strings are interpolated into React — React escaping is the primary XSS guard |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Tampering / XSS | Model name or deployment_state string rendered in DOM | mitigate | All interpolation uses JSX `{value}` (React auto-escapes). No `dangerouslySetInnerHTML` anywhere. Lint rule or code review gate. |
| T-02-07 | Information Disclosure | fetch error message leaking stack / URL to UI | mitigate | Hook sets a fixed user-facing string `'Connection lost — retrying…'` (UI-SPEC copy contract). Underlying error only console.errored in dev. |
| T-02-08 | Denial of Service | Unbounded setInterval after unmount | mitigate | useEffect cleanup clears both intervals + AbortController aborts in-flight fetch (RESEARCH Pitfall 6). |
| T-02-09 | Repudiation | No logging of who accessed the dashboard | accept | SYS-03 local-only; single user. Out of scope for v1. |
</threat_model>
