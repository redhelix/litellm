<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → dashboard-sidecar (4001) | Untrusted LAN client calls sidecar API; CORS preflight gates cross-origin access |
| build pipeline → browser bundle | Any env var prefixed VITE_ is inlined into JS shipped to the browser |
| dashboard container → host network | Dashboard serves static files only; it does not proxy auth or secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | VITE_SIDECAR_URL in bundle | accept | LAN hostname docker-001:4001 is non-secret; no credentials leaked. Explicitly exclude any VITE_ var that matches a secret pattern. |
| T-02-02 | Information Disclosure | LITELLM_MASTER_KEY | mitigate | Assertion in dashboard-sidecar/main.py already blocks master key; keep it. Add grep in CI/verify step that no `VITE_*KEY*` / `VITE_*SECRET*` var exists in dashboard/.env. |
| T-02-03 | Tampering | CORS misconfiguration | mitigate | `allow_origins` is a literal list `["http://docker-001:4002"]`, not `["*"]`. `allow_credentials` left default (False). Only GET allowed. |
| T-02-04 | Elevation of Privilege | SYS-03 no-auth exposure | accept | LAN-only by design (SYS-03). Traefik route (added in Plan 04) intentionally omits authentik middleware. Documented and user-acknowledged. |
| T-02-05 | Denial of Service | Uncapped polling from many clients | accept | Single-user lab; sidecar already behind docker restart policy + healthcheck. No rate limiting added. |
</threat_model>
