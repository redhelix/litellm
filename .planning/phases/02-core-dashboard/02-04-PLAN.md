1. Create `dashboard/Dockerfile` (multi-stage per RESEARCH §Docker):
```
FROM node:22-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```
2. Create `dashboard/nginx.conf`:
```
server {
    listen 80;
    root /usr/share/nginx/html;
    index index.html;
    location / { try_files $uri $uri/ /index.html; }
}
```
3. Create `dashboard/.dockerignore` with: `node_modules`, `dist`, `.env*` (but NOT `.env.production`), `*.log`, `.vite`, `coverage`.
4. **Important:** At build time, Vite inlines `import.meta.env.VITE_SIDECAR_URL`. Ensure the sidecar URL makes it into the image. Two options — pick (a) for simplicity:
   (a) Create `dashboard/.env.production` with `VITE_SIDECAR_URL=http://docker-001:4001` and remove it from `.dockerignore`; OR
   (b) Pass as ARG in Dockerfile: `ARG VITE_SIDECAR_URL=http://docker-001:4001` then `ENV VITE_SIDECAR_URL=$VITE_SIDECAR_URL` before `npm run build`, and set `--build-arg` in compose via `build.args`.
   Go with (a). Document in Dockerfile comment that `.env.production` is NOT secret (LAN hostname only — see T-02-01).
5. Add to `docker-compose.yaml` under `services:` (alongside `dashboard-sidecar`):
```yaml
  dashboard:
    build: ./dashboard
    image: dashboard:local
    container_name: dashboard
    restart: unless-stopped
    ports:
      - "4002:80"
    networks:
      - traefik-net
    labels:
      - "autoheal=true"
    healthcheck:
      test: ["CMD-SHELL", "wget -q -O /dev/null http://localhost/ || exit 1"]
      interval: 30s
      timeout: 5s
      retries: 3
      start_period: 15s
    logging:
      driver: "json-file"
      options:
        max-size: "50m"
        max-file: "3"
```
   Note: ONLY `traefik-net`. Do not attach `litellm-internal` — dashboard serves static files, API calls happen in the browser directly to docker-001:4001.
6. Build + deploy on docker-001:
   `ssh root@docker-001 "cd /root/litellm && git pull && docker compose up -d --build dashboard"`
7. Verify the endpoint: `curl -sS -o /dev/null -w "%{http_code}\n" http://docker-001:4002/` must return 200.
8. Verify no auth redirect: `curl -sS -o /dev/null -w "%{http_code}\n" http://docker-001:4002/` MUST NOT return 302 to any authentik URL.
9. Verify the built JS contains the correct sidecar URL:
   `curl -sS http://docker-001:4002/ | grep -Eo 'assets/[a-zA-Z0-9_.-]+\.js' | head -1 | xargs -I{} curl -sS "http://docker-001:4002/{}" | grep -o "docker-001:4001" | head -1` — must print `docker-001:4001`.

## STRIDE Threat Register

|-----------|----------|-----------|-------------|-----------------|
| T-02-14 | Elevation of Privilege | dashboard.thelaljis.com is public DNS | accept | SYS-03 explicit decision; user-acknowledged. Cloudflare DNS points the hostname at Traefik; Traefik route is intentionally unprotected. Documented in RESEARCH.md and services.yml commit message. |

| T-02-16 | Tampering | CORS bypass via forged Origin header | mitigate | Sidecar CORS allowlist set to exact string `http://docker-001:4002`. | T-02-17 | DoS | Unauthenticated DNS-facing endpoint | accept | Traffic is negligible (single user). Traefik terminates TLS; Cloudflare in front provides rate-limit defaults. No further rate limiting added. |
